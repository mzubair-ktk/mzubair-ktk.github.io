# Dr. Muhammad Zubair — Academic Website

This folder contains a ready-to-run static academic website created from the supplied CV.

## Files
- `index.html` — website content and structure
- `style.css` — responsive visual design
- `script.js` — publication search/filter and mobile navigation
- `Dr_Muhammad_Zubair_CV.pdf` — supplied CV, linked from the website
- `Dr_Muhammad_Zubair_Profile.jpg` — profile photograph displayed on the homepage

## How to preview
Double-click `index.html` to open it in a browser.

## How to publish
The site is a static HTML/CSS/JavaScript site and can be deployed on GitHub Pages, Netlify, Vercel, or another static web host.

## Before public deployment
Review contact details and publication metadata. The website currently uses the information contained in the supplied CV and does not invent missing social-media/ORCID/Google Scholar links.
